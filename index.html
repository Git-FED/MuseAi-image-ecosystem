LIVE OPS — WHO IS DOING WHAT, AND WHEN

This is the live engine for this page, built the way real agent fleets are wired: the server owns the truth, and the map only renders what the server says. On this static GitHub Pages build the server is a module inside the page — there is no network server behind a Pages site; the full network-server version of this ecosystem is the Space. Inside this page the split is strict all the same: The server creates the job, and for every move it issues an agent's whole route — waypoints, departure time and speed — for deploys and workstation patrols during a run. No route is issued while no pipeline is running, so every agent holds its post and does not move until you start a pipeline. The map animates those routes locally at 60 frames a second, but no animation starts, stops or changes direction except when the server's state changes. The server reports every agent four times a second; if an agent ever stops reporting, it is marked OFFLINE with its last-seen time and its animation holds — it never keeps walking on its own. No anonymous dots do job work — the 12 named crew below do. The smaller background dots are street traffic only, and they only move while a job is live.

      README

      WHAT IT IS

      The Muse AI Image Ecosystem is a working image pipeline drawn the way the ecosystem is supposed to look: a top-down satellite view on a dark grid, rooms as blocks, corridors like streets, and AI agents as little moving dots travelling room to room. You write a brief; the ecosystem turns it into a finished image, stage by stage, in the open — and shows you the exact prompt it built along the way.

      THE SIX ROOMS

      • R01 Prompt Office — expands your one-line brief into a full descriptive prompt.
      • R02 Style Lab — locks the style, mood, lighting and palette.
      • R03 Composition Bay — frames the shot for the format you picked: square, landscape or portrait.
      • R04 Detail Forge — sharpens detail language and applies your keep-out list. The forge runs before the render, in the true stage order.
      • R05 Render Engine — generates the image; on this Pages build it renders live on a canvas in your browser. The painter reads the subject in your brief — a cat, a rocket, a castle, a coastline each get their own scene — and trees appear only when the brief actually asks for a forest. This is the slow step of the run.
      • R06 Gallery Vault — where finished work lands, and where Photo Scout, the Vault's search worker, files the real openly licensed photos it finds for your brief.

      WHO THE AGENTS ARE — AND WHERE THEY DEPLOY FROM

      Job work is done by 12 named agents, two per room, each based in its own room and holding still at its post whenever no job is running — the crew does not move unless the pipeline is started. Quill + Scribe work R01 Prompt Office, Palette + Mood R02 Style Lab, Frame + Rule R03 Composition Bay, Hone + Polish R04 Detail Forge, Forge + Kiln R05 Render Engine, and Vault + Courier R06 Gallery Vault — Courier also runs the carry from R05 to R06 through the bay. When a stage fires, that room's pair routes through the bay, travels the streets to its workstation, and works there; when the stage closes, the pair returns to its post and stops. Each agent's name rides with it on the map, its room shows what it is doing, and its card, the Agent Inspector and the feed all show the same live task string, so there is one answer to “who is doing what” everywhere you look.

      THE LIVE ENGINE (SERVER OWNS THE TRUTH)

      GitHub Pages has no network server to add, so the server lives in the page as a module — but the split is the real one used by live agent fleets. The server owns every agent's state and is the only thing that can change it: it creates a numbered job from your brief, and for every move it issues the agent's whole route — waypoints, departure time and speed — covering deploys routed through the Deployment Bay and patrol legs around a workstation while a stage runs. While no job is running it issues no routes at all, so the crew sits at its posts. The map is a renderer only: it animates the server's routes locally at 60 frames a second and never starts, stops or redirects a walk by itself. The server reports every agent four times a second and appends every deployment, arrival, handoff and filing to a timestamped event log (the Deployment Feed and terminal); an agent whose reports go stale is marked OFFLINE with its last-seen time and its animation holds until it reports again. The 18 smaller dots are street traffic only — they stay held at rest and move only during a run, and they never carry a job. The full server version of this ecosystem is the Space; this Page is its live public face.
